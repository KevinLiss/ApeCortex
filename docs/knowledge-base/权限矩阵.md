# ApeCortex 权限矩阵（v0.4.0 实测基线）

> 用途：新增角色/动作分支时对照本表，防止再出现「新分支漏校验」类越权。
> 可复跑：`cd backend && python -m pytest tests/test_permission_matrix.py -q`（40 条，4 角色 × 10 组动作）

## 一、角色

| 角色 | 定义 | 来源 |
|---|---|---|
| **owner** | 空间创建者 | `kb_space.owner_user_id` |
| **writer** | 共享空间可写成员 | `kb_space_member.role = writer` |
| **reader** | 共享空间只读成员 / 公开空间的任意登录用户 | `kb_space_member.role = reader` 或 `visibility = public` |
| **stranger** | 非成员（仅对私有/共享空间而言） | 无成员记录 |

## 二、矩阵

### 共享空间（shared）

| 动作 | owner | writer | reader | stranger | 实现位置 |
|---|---|---|---|---|---|
| 读空间/词条列表 | ✓ | ✓ | ✓ | ✗ | `get_space_role` / `get_pages` |
| 读词条详情/修订 | ✓ | ✓ | ✓（live/draft） | ✗ | `get_page` / `get_revisions` |
| 上传文档（触发编译） | ✓ | ✓ | ✗ | ✗ | `ensure_space_access(need_write=True)` |
| 编辑词条 | ✓ | ✓ | ✗ | ✗ | `put_page` |
| 改状态（发布/归档） | ✓ | ✓ | ✗ | ✗ | `publish_page` |
| 提交晋升 | ✓ | ✗ | ✗ | ✗ | `submit_promotion` |
| AI 召回 | ✓（私有通道） | ✓（共享通道） | ✓（共享通道） | ✗ | `search_all` |

> **owner 通道说明**：owner 的共享空间词条走「私有通道」召回（`owner_user_id == 当前用户`），
> 结果仍标记 `visibility=shared`，不会重复出现在共享通道。

### 公开空间（public）

| 动作 | owner | writer | reader | stranger | 说明 |
|---|---|---|---|---|---|
| 读/召回 live | ✓ | ✓ | ✓ | ✓ | 任何登录用户 |
| 召回 draft/candidate | ✗ | ✗ | ✗ | ✗ | 仅 `live` 进公开召回 |
| 上传文档 | ✓ | ✗ | ✗ | ✗ | owner 可直接向公开库投料 |
| 编辑 / 改状态 | ✓ | ✗ | ✗ | ✗ | 维护者 = 空间 owner |
| 提交晋升 | ✓ | ✗ | ✗ | ✗ | 需是来源空间的 owner |
| 审核晋升 | 需 `promotion:review` 权限；**不能审自己提交的**（可由 `promote_allow_self_review` 放开） | | | | `review_promotion` |

### 私有空间（private）

| 动作 | owner | 其他所有人 |
|---|---|---|
| 读 / 写 / 发布 / 召回 | ✓ | ✗（列表不可见、详情 404、召回无路径） |

### 公开库只读出口（外部 AI）

| 约束 | 实现 |
|---|---|
| 仅 `public` 空间 + `live` 词条 | SQL 层 `join KbSpace` + 双重 where，无其他读取路径 |
| 鉴权 | `X-Kb-Key`（sha256 存库，明文只显示一次） |
| 限流 | 每凭证 60 秒 10 次（进程内窗口） |
| 审计 | `request_count` / `last_used_at` + 日志 |
| 写能力 | 无任何写入端点 |

## 三、已修复的越权（记录）

| 版本 | 问题 | 根因 | 修复 |
|---|---|---|---|
| v0.4.0 补丁（`a95b9de`） | reader 成员可把共享库草稿改为 live | `publish_page` 只判断 public/private 两个分支，`shared` 不落任何分支 | 显式分支：shared 要求 owner 或 writer |

## 四、复跑结果

```
$ python -m pytest tests/test_permission_matrix.py -q
40 passed
```

覆盖组合：shared × {读, 写, 发布, 召回, 晋升}、public × {写, 读, 召回}、private × {写, 读}，
每个动作 4 个角色。
