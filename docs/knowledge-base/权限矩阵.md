# ApeCortex 权限矩阵（v0.8.0 周期三基线）

> 用途：新增角色/动作分支时对照本表，防止再出现「新分支漏校验」类越权。
> 可复跑：`cd backend && python -m pytest tests/test_permission_matrix.py -q`（14 条）

## 一、角色（周期三：空间无类型、无成员体系）

| 角色 | 定义 | 来源 |
|---|---|---|
| **owner** | 个人空间创建者（唯一读写者） | `kb_space.owner_user_id` |
| **登录用户** | 任何认证用户 | 路由 `get_current_user` |
| **系统（0）** | 知识中心空间所有者 | `owner_user_id == 0`，无人类 owner |

周期三用户决策（2026-11-26）：共享空间/成员管理/晋升流全部下线；
知识中心 = 唯一公共库（hub 单例）。

## 二、矩阵

### 个人空间（全部空间）

| 动作 | owner | 其他所有人 | 实现位置 |
|---|---|---|---|
| 读空间/词条列表/详情 | ✓ | ✗（403/404） | `get_space_role` / `get_pages` / `get_page` |
| 编辑空间（名称/描述） | ✓ | ✗ | `update_space` |
| 删除空间（级联清内容） | ✓ | ✗ | `delete_space` |
| 上传文档 / 编辑词条 / 改状态 | ✓ | ✗ | `ensure_space_access(need_write=True)` / `put_page` / `publish_page` |
| 推送知识中心 | ✓（仅 owner） | ✗ | `submit_public_content` |
| AI 召回（私库通道） | ✓ | ✗（SQL 硬过滤 `owner_user_id == user_id`） | `search_all` |

### 知识中心（hub 单例，owner_user_id=0）

| 动作 | 任何登录用户 | 说明 |
|---|---|---|
| 召回 live 词条 | ✓ | hub 通道；draft/candidate/archived 不进召回 |
| 直接写（上传/编辑/改状态） | ✗ | hub 无人类 owner，`ensure_space_access` 对所有人返回 False |
| 写入唯一路径 | 推送流 | `submit_public_content`（源空间 owner）→ AI 甄选 → 自动入库 |

### 推送流（submission 管线）

| 环节 | 权限 | 说明 |
|---|---|---|
| 发起推送 | 源空间 owner | 快照冻结 + 幂等（同内容在途/已入库拒重复） |
| AI 甄选 | 系统 | 1 次 LLM：分类（可建新分类）/违规判定/拆解预览；CAS 认领防并发双跑 |
| 自动入库 | 系统（reviewer_id=0） | 无审批环节；留痕可复查登记（不改结果） |
| 判违规处置 | `submission:dispose` 权限 | 保留存证 / 清理内容快照（记录行保留） |

### 知识中心只读出口（外部 AI）

| 约束 | 实现 |
|---|---|
| 仅 hub 单例 + `live` 词条 | SQL 层 `space_id == hub_id` 双重 where，无其他读取路径 |
| 鉴权 | `X-Kb-Key`（sha256 存库，明文只显示一次） |
| 限流 | 每凭证 60 秒 10 次（进程内窗口） |
| 审计 | `request_count` / `last_used_at` + 日志 |
| 写能力 | 无任何写入端点 |
