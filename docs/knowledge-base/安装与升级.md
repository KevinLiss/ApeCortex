# ApeCortex 安装与升级

> ApeCortex = Ape（ApeAdmin）+ Cortex（大脑皮层）。Python 包名保持 `knowledge_base`。
> 本文覆盖：安装、权限配置、联网合规、升级与回滚、故障排查。

---

## 一、安装

### 1. 随仓库内置（开发环境）

```bash
# 后端
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .

# 前端（另开终端）
cd frontend
npm install
npm run dev
```

启动后访问 `http://localhost:5173`，完成安装向导，在「插件管理」中确认 **ApeCortex** 为启用状态。首次启用会自动建表、注册菜单与权限点。

### 2. 以插件包安装（已有 ApeAdmin 实例）

1. 进入「插件管理」→「上传插件」→ 选择 `knowledge_base-<version>.zip`
2. 上传成功后插件自动启用并注册菜单（无需重启，菜单出现在侧边栏「ApeCortex」分组）
3. 若为升级安装，旧版本文件会备份到 `backend/src/plugins/_backups/knowledge_base/`（保留最近 2 个版本）

> **包结构约定（必须遵守）**：zip 根目录同时包含 `plugin.json` 与 `knowledge_base/` 目录。
> 仅含 `knowledge_base/` 一个顶层目录的包会被宿主误判为"外层壳"而解压失败（宿主缺陷待修）。
> 打包命令见 `docs/knowledge-base/插件开发规划.md` 第十一节。

### 3. 可选依赖

| 依赖组 | 用途 | 说明 |
|---|---|---|
| `knowledge-render` | JS 渲染站点抓取（`crawl4ai`） | Apache-2.0；不装不影响核心，抓取失败时给明确提示 |

```bash
pip install -e ".[knowledge-render]"
```

## 二、权限配置（装完必须做）

插件注册 16 个权限点（`knowledge_base:*`）。但**普通角色在聊天里使用知识库工具还需要宿主的 MCP 总开关**：

| 权限 | 作用 | 用户是否必须 |
|---|---|---|
| `knowledge_base:profile:list` / `:delete` / `:rewrite` | 记忆画像页 | 是 |
| `knowledge_base:space:list` / `:create` | 知识空间 | 是 |
| `knowledge_base:page:list` / `:edit` / `:publish` | 词条管理 | 是 |
| `knowledge_base:promotion:submit` / `:review` | 晋升提交 / 审核 | 提交者 / 维护者 |
| `knowledge_base:task:list` / `:retry` | 任务中心 | 是 |
| `knowledge_base:setting:read` / `:update` | 插件设置（联网开关） | 维护者 |
| **`mcp:tools:call`** | **MCP 工具调用总开关** | **是（聊天里用 `kb_*` 工具的前提）** |

> 缺 `mcp:tools:call` 的典型症状：AI 回复「权限不足，无法调用 MCP 工具: kb_query」。
> 超管（`permissions = ["*"]`）不受影响。

**公开库维护者**需要：`knowledge_base:promotion:review`（同时获得创建公开空间、审核晋升的资格）。
公开空间只有其 owner 能发布 `draft → live`。

## 二·五、共享空间与对外出口（M3）

### 共享空间（团队协作）

- 新建空间时可选「共享（成员可访问）」；成员分为 **只读（reader）** 与 **可写（writer）**
- 只读成员：浏览词条、AI 召回命中；不能上传文档/编辑
- 可写成员：额外可上传文档、编辑词条（公开库仍仅 owner 可编辑与发布）
- 成员管理在空间卡片「成员」按钮（仅 owner 可见）；添加时填用户数字 ID
- 召回第三通道：共享空间内容仅成员可见，SQL 层成员连接过滤，非成员无召回路径

### 公开库只读出口

- 「插件设置 → 公开库只读凭证」创建 `kbp_...` 凭证（明文只显示一次）
- 外部调用：
  ```bash
  curl -H "X-Kb-Key: kbp_xxx" "http://<host>/api/v1/knowledge-base/public/search?q=关键词"
  curl -H "X-Kb-Key: kbp_xxx" "http://<host>/api/v1/knowledge-base/public/pages/<slug>"
  ```
- 只返回 `public` 空间且 `live` 的词条；草稿/候选/私有/共享内容在该路由的 SQL 中不存在读取路径
- 每凭证限流 10 次/分钟；调用次数与最近使用时间可在设置页查看；吊销立即生效

## 三、联网与合规

- **联网开关默认关闭**：开启时弹窗明确告知"数据将外发至目标站点"，API 侧还要求 `confirm=true`，缺省拒绝。
- **域名白名单**：留空表示只受 SSRF 防线约束（私网地址一律拦截）。
- **学术检索（arXiv / OpenAlex / Semantic Scholar）不走开关**：它们是公开元数据接口，只读元数据。
- **抓取护栏**：仅 http/https、私网拦截、robots.txt 检查、响应 ≤5MB、仅 HTML/文本类型。

## 四、升级与回滚

### 升级

1. 「插件管理」直接上传新版本 zip；同版本重装视为修复，低版本默认拒绝（需 `allow_downgrade`）
2. 升级流程：卸载运行实例 → 旧文件移至 `_backups` → 解压新包 → `on_load` / `install()` → 重新注册路由/工具/菜单
3. 数据库表为幂等建表（插件启动时自查），不删除既有数据；升级前不影响词条/记忆/晋升记录

### 回滚

- 管理页「备份回滚」选择 `_backups/knowledge_base/<version>-<timestamp>`
- 或手动：停止服务 → 用备份目录替换 `src/plugins/builtin/knowledge_base` → 重启

> 迁移只增不删：回滚到旧版本时新版本新增的列会保留（不影响旧代码读取）。

## 五、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面提示「接口不存在：后端可能未加载最新代码」 | 后端进程是旧代码（新增路由未加载） | 重启后端；开发环境用 `--reload` |
| AI 回复「权限不足，无法调用 MCP 工具」 | 角色缺 `mcp:tools:call` | 到「角色管理」补权限后重新登录 |
| 抓取失败：`ConnectTimeout` | 目标站点不可达（网络/代理） | 换可达站点；检查是否需要代理 |
| 抓取失败：「该站点需要渲染引擎」 | 未装 `knowledge-render` extras | `pip install -e ".[knowledge-render]"` |
| 晋升提示「未达晋升门槛」 | `source_count < 3` 或 `confidence < 0.8` | 补充资料来源重新编译；门槛在 `compiler.py` 常量可调 |
| 批准后公开库看不到词条 | 副本落 `draft`，需公开空间 owner 发布 | 在「词条管理」选中该词条点「发布」 |
| 上传 zip 报「解压后未找到 knowledge_base/__init__.py」 | zip 结构不符合约定 | 按第一节的包结构重新打包 |
| 任务一直 pending | 后台 worker 未启动 / 队列异常 | 查后端日志；「任务中心」点重试 |
| 提示「今日任务已达上限」 | 设置了 `kb_setting.daily_job_limit` | 到设置页调大或设为 0（不限）；次日自动重置 |
| 公开出口返回 401 / 429 | 凭证无效或超限流 | 重新创建凭证；限流 10 次/分钟，等待窗口重置 |

## 六、验证清单（装完自检）

1. 侧边栏出现 **ApeCortex** 分组与 6 个子页
2. 「记忆画像」能显示统计与记忆列表（与 AI 聊 3~5 轮后产生）
3. 「知识空间」可新建空间、上传文档；「任务中心」出现 `Wiki 编译` 任务并完成
4. 「词条管理」能看到生成的候选词条与来源引用
5. 在聊天中问「用 kb_query 查一下知识库里有什么」，AI 能调用工具并返回结果
6. 「插件设置」开启联网开关有确认弹窗，保存后刷新仍为开启
7. 新建「共享」空间并添加成员，成员账号能在空间列表看到该库
8. 设置页创建只读凭证，用 `X-Kb-Key` 访问 `/public/search` 能返回 live 词条
